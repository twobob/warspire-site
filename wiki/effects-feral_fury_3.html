How status effects work

What it does

A unit with this effect: +13 attack damage.

This counts as a buff.

Stacking and duration

  • Each new application adds a stack, up to 99 stacks. Every stack adds the full values again, and each application also renews the duration.

See How status effects work for how effects stack, renew and expire, and Stat reference for what each stat means.
